# SimpleKeys - カスタマイズ可能なiOSキーボード

SimpleKeysは、スピードと柔軟性、そして美しいネイティブ感を追求した、高度にカスタマイズ可能な軽量iOSキーボード拡張アプリです。日本語のフリック入力と英語のQWERTY入力の両方に対応し、充実したテーマ着せ替え機能を備えています。

## 主な機能

- **デュアルレイアウト**: 日本語かな（フリック）と英語QWERTYレイアウトをシームレスに切り替え。
- **ディープカスタマイズ**:
  - **キーとポップアップの形**: 角丸、楕円、四角に加え、星、三角形、五角形、六角形、吹き出しなど多彩な図形をキーやポップアップに適用可能。
  - **キースタイル**: フラット、すりガラス、クリアガラスの3つのスタイルに対応。
  - **色と透明度**: 背景色、文字色、ハイライト色、全体の透明度を自由に設定可能。
  - **動的フォント**: アクセシビリティや好みに合わせて、キーボード全体のフォントスタイルや文字サイズを調整可能。
- **メディア背景**: カメラロールにある好きな画像や動画をキーボードの背景に設定可能。
- **ハプティックフィードバック**: 振動の強さを調整できる快適な打鍵感。
- **プライバシーファースト**: 「フルアクセスを許可」は、カスタムテーマやフォント、振動機能の適用にのみ使用されます。入力したテキストはすべてデバイス内で処理され、外部に送信されることは一切ありません。

## インストール方法

1. Xcode経由でアプリをビルドし、iOSデバイスにインストールします。
2. デバイスの **設定** アプリを開きます。
3. **一般 > キーボード > キーボード > 新しいキーボードを追加...** に進みます。
4. **SimpleKeys** を選択します。
5. 追加された **SimpleKeys** をタップし、**「フルアクセスを許可」**をオンにします（カスタムテーマを読み込むために必要です）。

## 使い方

1. **SimpleKeys** 本体アプリを開き、お好みのテーマを設定します。
2. **プレビュー** 画面で、変更がリアルタイムにどのように反映されるかを確認できます。
3. 任意のアプリで文字入力画面を開き、地球儀アイコン `🌐` をタップしてキーボードを切り替えます。

## オープンソース

このプロジェクトは、`CAShapeLayer` を用いた高度なマスク処理、`UIInputViewController` のライフサイクル管理、および `AppGroups` を利用したアプリ・拡張機能間のデータ共有など、モダンなiOSカスタムキーボードの実装手法を示すためのデモンストレーションとして構築されています。
