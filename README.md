SimpleKeys is a highly customizable, lightweight iOS keyboard extension designed for speed, flexibility, and a beautiful native feel. It supports both Japanese Flick input and standard QWERTY layouts with comprehensive theming capabilities.

## Features

- **Dual Layouts**: Seamlessly switch between Japanese Kana (Flick) and English QWERTY layouts.
- **Deep Customization**:
  - **Key Shapes**: Choose from Rounded, Oval, Rectangle, Star, Triangle, Pentagon, Hexagon, and Speech Bubble for both keys and popup menus.
  - **Key Styles**: Support for Flat, Frosted Glass, and Clear Glass looks.
  - **Colors & Transparency**: Customize background colors, text colors, highlight colors, and overall opacity.
  - **Dynamic Fonts**: Adjust font styles and font sizes across the entire keyboard to suit your accessibility needs or aesthetic preferences.
- **Media Backgrounds**: Set any image or video from your camera roll as the keyboard background.
- **Haptic Feedback**: Enjoy tactile typing with adjustable vibration strength.
- **Privacy First**: SimpleKeys requires "Full Access" only for applying your custom themes, fonts, and haptics. Your keystrokes are processed locally and are never transmitted off-device.

## Installation

1. Build and install the app on your iOS device via Xcode.
2. Open the **Settings** app on your device.
3. Navigate to **General > Keyboard > Keyboards > Add New Keyboard...**
4. Select **SimpleKeys**.
5. Tap on the newly added **SimpleKeys** and enable **Allow Full Access** (required to load your custom themes).

## Usage

1. Open the **SimpleKeys** main app to configure your themes.
2. Use the **Preview** section to see your changes in real-time.
3. Switch to the keyboard in any app by tapping the globe icon `🌐`.

## Open Source

This project is built to demonstrate modern iOS Custom Keyboard Extension capabilities including `CAShapeLayer` masking, `UIInputViewController` lifecycles, and `AppGroups` for sharing user preferences.
